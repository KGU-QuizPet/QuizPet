## 문서 요약

QuizPet은 사용자가 과학&상식, 스포츠, 역사, 언어(영어) 분야의 지식을 학습하고 퀴즈를 풀어 애완 캐릭터를 성장시키는 교육형 데스크톱 게임이다. 학습 성과를 경험치와 능력치로 연결하여 반복 학습의 동기를 제공한다.

| **구분** | **핵심 정의** |
| --- | --- |

| 핵심 기능(P0) | 사용자/캐릭터 관리, 학습 카드, OX·4지선다, 보상, 기록 및 저장 |
| 추가 기능(P1) | 오답노트, 단답형 퀴즈, 캐릭터 진화 |

## 1. 프로젝트 개요

### 1.1 프로젝트 소개

QuizPet은 다양한 분야의 지식을 학습하고 퀴즈를 해결하며 자신만의 애완 캐릭터를 육성하는 교육형 게임이다. 사용자는 학습 분야를 선택하여 관련 지식을 습득한 뒤 OX 및 객관식 퀴즈로 이해도를 확인한다. 정답 여부에 따라 경험치와 분야별 능력치가 부여되며, 성장이 시각적으로 표시된다.

### 1.2 추진 배경

일반적인 학습 프로그램은 콘텐츠 열람과 문제 풀이에 집중되어 학습 참여를 지속적으로 유지하기 어렵다. 본 프로젝트는 캐릭터 육성의 보상 구조를 결합하여 학습을 반복할 이유와 성취감을 제공하고자 한다.

### 1.3 프로젝트 목표

1. 다양한 분야의 학습 자료 제공 및 정보 습득 지원
2. OX·객관식 퀴즈를 통한 이해도 확인 및 피드백 제공
3. 정답 보상에 따른 캐릭터 레벨과 능력치 성장
4. 학습 기록과 오답 확인을 통한 반복 학습 지원
5. 캡슐화·상속·다형성 등 객체지향 원칙을 적용한 확장 가능한 구조 설계

## 4. 상세 기능 요구사항

### 4.1 사용자 관리

#### FR-001 사용자 프로필 생성

- 닉네임 입력으로 사용자 프로필 생성
- 닉네임은 공백 제외 1~12자 제한, 중복 닉네임 생성 방지
- 사용자별 고유 ID 부여

#### FR-002 사용자 프로필 선택

- 저장된 프로필에서 기존 사용자 선택
- 선택 프로필의 캐릭터와 학습 기록 로드
- 프로필별 데이터 독립 관리

### 4.2 캐릭터 시스템

#### FR-003 캐릭터 생성

- 캐릭터 이름 지정 및 제공되는 외형 2~3종 중 한 가지 선택
- 최초 레벨 1, 최초 경험치 0
- 한 사용자당 캐릭터 1개를 기본으로 설정

#### FR-004 캐릭터 능력치

- 4개 능력치(체력/지성/집중력/지혜) 보유, 각 초기값 10
- 최초 정답 보상 시 과학&상식→지성(INT), 스포츠→체력(STR), 역사→지혜(WIS), 언어(영어)→집중력(FOC) 증가
- 상태 화면에서 현재 능력치 표시

| **능력치** | **성격** | **관련 학습 분야** |
| --- | --- | --- |
| 체력(STR) | 신체형 | 스포츠 |
| 지성(INT) | 지식형 | 과학&상식 |
| 집중력(FOC) | 집중형 | 언어(영어) |
| 지혜(WIS) | 판단형 | 역사 |

#### FR-005 경험치 및 레벨업

- 문제 최초 정답: 경험치 +10, 해당 능력치 +1
- 오답 및 동일 문제 재정답: 성장 보상 없음
- 누적 경험치가 기준에 도달하면 레벨 상승
- MVP의 레벨당 필요 경험치: 50(초기 기획값)
- 재도전 정답은 학습 이력에 남기되 반복 보상은 방지

성장 수치는 초기 테스트용 기획값으로, 게임 밸런스 점검 후 조정할 수 있다.

### 4.3 학습 시스템

#### FR-006 학습 분야 선택

- 과학&상식, 스포츠, 역사, 언어(영어) 네 분야 제공
- 분야 ID와 성장 능력치의 매핑 정보 관리

#### FR-007 학습 콘텐츠 조회

- 선택한 분야의 개념 카드를 제목·설명·난이도로 제공
- 학습 콘텐츠와 해당 퀴즈 문제를 연결
- 학습 종료 후 관련 분야의 퀴즈로 진입

### 4.4 퀴즈 시스템

#### FR-008 OX 퀴즈

- 문제 문장 제시 및 O 또는 X 선택
- 선택 답과 정답 비교 후 결과 및 해설 제공

#### FR-009 4지선다 퀴즈

- 문제와 선택지 4개 표시
- 선택 답의 정오 판별 및 해설 제공

#### FR-010 퀴즈 진행

- 선택 분야에서 5문제를 무작위 출제(5개 미만이면 가능한 수만큼)
- 동일 퀴즈 세션 내 문제 중복 방지
- 문제당 답변 제출은 1회만 허용
- 제출 후 해설을 확인한 다음 문제로 이동
- 퀴즈 종료 시 정답 수·정답률·획득 경험치 표시

#### FR-011 정답 해설

- 정답과 오답 모두 해설 제공
- 오답일 경우 올바른 정답 표시
- 관련 학습 카드로 되돌아갈 수 있도록 지원

### 4.5 학습 기록

#### FR-012 풀이 결과 저장

- 문제별 사용자 ID·문제 ID·선택 답·정답 여부·풀이 시각·획득 경험치 저장
- 동일 문제의 반복 풀이도 별도 기록으로 관리

#### FR-013 학습 통계

- 총 문제 풀이 횟수 및 전체 정답률 표시
- 분야별 정답률과 최근 학습 기록 조회
- 누적 경험치 확인

#### FR-014 오답노트(P1)

- 오답 문제 목록 조회 및 재도전 제공
- 재도전 결과 역시 별도의 풀이 기록으로 저장

### 4.6 캐릭터 결투(P2)

#### FR-015 로컬 캐릭터 대결

- 동일 PC의 사용자 캐릭터 2개 선택
- 능력치 기반 턴제 공격·방어 행동 처리
- 캐릭터 HP가 0이 되면 결과 표시
- 온라인 실시간 PvP와 서버 연동은 제외

## 5. 화면 구성 및 이동 흐름

| **화면 ID** | **화면명** | **주요 기능** |

| UI-03 | 메인 화면 | 펫 정보, 레벨·경험치·능력치, 메뉴 |
| UI-04 | 분야 선택 | 학습 분야 선택 |

| UI-08 | 학습 기록 | 학습 내역, 통계, 오답 확인 |

### 5.1 화면 이동 흐름

UI-01 시작 화면 → 신규 사용자: UI-02 캐릭터 생성 → UI-03 메인 화면

UI-01 시작 화면 → 기존 사용자: UI-03 메인 화면

UI-03 메인 화면 → UI-04 분야 선택 → UI-05 학습 카드 → UI-06 퀴즈 → UI-07 결과 → UI-03 메인 화면

UI-03 메인 화면 ↔ UI-08 학습 기록 / UI-09 결투(P2)

## 6. 데이터 요구사항

### 6.1 데이터 구성 및 예상 건수

| **데이터** | **주요 정보** | **예상 개수** |
| --- | --- | --- |
| 사용자(user.txt) | 사용자 ID, 닉네임, 생성 일시 | 초기 0개 / 테스트 10개 |
| 캐릭터(pet.txt) | 이름, 외형, 누적 XP, 체력·지성·집중력·지혜 | 초기 0개 / 테스트 10개 |
| 학습 분야(category.txt) | 4개 분야 및 연결 능력치 | 4개 |
| 학습 카드(content.txt) | 제목, 내용, 난이도, 태그 | 40개 |
| 퀴즈 문제(question.txt) | 문제, 보기, 정답, 해설 | 80개 |
| 풀이 기록(record.txt) | 제출 답, 정오, 보상, 풀이 일시 | 초기 0개 / 테스트 약 100개 |
| 결투 기록(battle.txt, P2) | 두 캐릭터, 승자, 턴 수, 일시 | 초기 0개 / 테스트 약 20개 |

학습 분야·카드·문제는 사전에 작성하며, 사용자·캐릭터·풀이 기록은 실행 중 생성한다. 풀이 기록과 결투 기록은 초기 0개이며 테스트 이후 사용량에 따라 누적된다.

### 6.2 저장 방식

- TXT(UTF-8): category.txt, content.txt, question.txt — data/content 폴더의 사전 작성 자료
- TXT(UTF-8): user.txt, pet.txt, record.txt — data/save 폴더의 실행 중 생성 정보
- 캐릭터 외형 2~3종 및 UI 이미지: PNG 등 이미지 리소스 사용(프로그래밍 언어 아님)
- 저장·불러오기는 Java 표준 파일 입출력(java.io / java.nio.file)으로 구현하며, 인터넷 연결은 필요하지 않음

| QuizManager | 문제 출제·세션 진행·채점 |
| GrowthManager | 정답 보상 및 성장 계산 |
| LearningRecord | 문제별 학습 이력 |
| SaveManager | 영속 데이터 저장·조회 |
| BattleManager(P2) | 전투 진행 및 승패 결정 |

### 7.2 객체지향 원칙 적용

- 캡슐화: 캐릭터 경험치와 능력치를 직접 수정하지 않고 정의된 메서드로 관리
- 상속: Question 추상 클래스를 OXQuestion 및 MultipleChoiceQuestion이 상속
- 다형성: 질문 유형에 관계없이 공통 정답 검증 메서드로 처리
- 책임 분리: Swing UI는 입력·출력, 서비스 계층은 채점·성장 로직을 담당

## 10. 테스트 및 완료 기준

### 10.1 기능 테스트

| **검증 항목** | **수용 기준** |
| --- | --- |
| 사용자 생성·선택 | 신규 계정을 생성하고 기존 사용자로 재진입할 수 있다. |
| 캐릭터 생성 | 사용자와 연결된 초기 펫 및 능력치가 생성된다. |
| 학습 콘텐츠 | 선택 분야의 콘텐츠만 정확히 표시한다. |
| 퀴즈 출제 | 분야별 중복 없는 문제 출제 및 답변이 가능하다. |
| 정답 판별 | OX 및 4지선다 채점 결과가 데이터 정답과 일치한다. |
| 보상 및 레벨업 | 최초 정답만 성장 보상 지급, 기준 충족 시 레벨 상승 |
| 중복 보상 방지 | 같은 문제의 재정답으로 추가 성장 보상이 발생하지 않는다. |
| 학습 기록 | 문제별 이력이 정확히 저장되고 사용자별로 분리된다. |
| 데이터 저장 | 재실행 후 사용자·펫·학습 데이터가 복원된다. |

### 10.2 최종 성공 기준

- 학습 분야 4개(과학&상식/스포츠/역사/언어(영어)), 학습 콘텐츠 40개 이상
- 퀴즈 문제 80개 이상 및 OX·4지선다 정상 작동
- 캐릭터 경험치, 레벨, 4개 능력치 성장 구현
- 사용자별 학습 기록과 정답률 조회
- 프로그램 종료 후 정보 유지 및 통합 테스트 완료

## 13. 최종 기대 효과

QuizPet은 학습 결과를 캐릭터의 성장으로 가시화하여 반복 학습과 성취감을 유도한다. 사용자는 정답률 및 학습 기록을 통해 자신의 성취도와 부족한 분야를 파악할 수 있다.

개발 측면에서는 사용자, 캐릭터, 학습 정보, 문제, 풀이 기록을 독립적인 객체로 모델링하고 상속·다형성·캡슐화·객체 간 협력을 실제 Java Swing 프로그램에 적용한다.
