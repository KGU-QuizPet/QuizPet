# 콘텐츠와 기존 기록 호환성

question-legacy.txt는 콘텐츠 교체 직전 커밋 4f1492f36faa73ee10cbf488c321816ca46d129c의 data/content/question.txt 원본입니다(80문제). 신규 225문제와 공통 ID는 0개입니다. 새 ID와 과거 ID 사이의 의미 동일성은 확정하지 않으며 변환하지 않습니다.

RecordQuestionLookup은 기록·통계 조회에서만 현재 문제와 보존 문제를 사용합니다. QuizService는 현재 question.txt만 출제합니다. record.txt의 필드·정오·XP·시각은 변경하지 않습니다. 다른 ID의 새 문제는 기존 보상 규칙상 별개 문제입니다. 의미가 비슷한 신규 문제에도 보상을 제한할지는 별도 정책 합의가 필요합니다.

알 수 없는 ID는 전체 기록에서 ID·원래 답안·정오·XP와 함께 표시합니다. 전체 통계에는 포함하되 분야를 추측하지 않습니다. 미분류 기록이 있으면 전체 화면의 분야별 요약은 제공하지 않으며 분야 선택 시에도 안내와 함께 전체 통계·기록으로 전환합니다. StatisticsService 자체의 누락 문제 예외 계약은 유지합니다. 보존 파일 부재는 출처 불명 처리하며, 파일이 존재하지만 비거나 손상된 경우에는 로딩을 거부하고 저장 파일은 수정하지 않습니다. 같은 ID가 다른 원문·분야로 재사용되면 로딩을 거부하여 잘못된 기록 해석을 막습니다.

SA는 PRD의 P1 확장이지만 기능명세서는 OX/객관식만 정의합니다. PR #45는 데이터만 변경하고 SA 코드 지원은 포함하지 않는다고 명시했습니다. 현재 75개 SA는 QuestionRepository의 기존 경고와 함께 제외됩니다. 지원하려면 BE2 모델·파서·대체답안 및 공백/대소문자 정책, FE2 입력 UI, FE3 답안 표현을 합의해야 합니다. 이번 작업에서는 채점 규칙을 임의로 추가하지 않습니다.

COMMON은 PR #46의 Category.getStatType()에서 INT로 정의되며 문서의 과학&상식→INT와 일치합니다. 문서의 4분야 표와 실제 5분야 표기는 후속 정리가 필요합니다.
